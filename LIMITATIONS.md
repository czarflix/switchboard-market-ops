# Limitations

- The hosted demo is a gated review build rather than a public self-service deployment.
- Live telephony, outbound messaging, purchasing, and other consequential actions are intentionally not enabled for the portfolio demo.
- Provider availability, rate limits, page changes, and model responses can change the workflow outcome.
- The repository does not claim production scale, regulatory compliance, or security guarantees.
- Evaluation scripts provide repeatable checks, but this repository does not yet publish a representative benchmark with measured end-to-end metrics.
